# 北方林におけるCOSフラックス予測モデル（LSTM）の追試実装

## プロジェクトの概要
本プロジェクトは、北方林（フィンランド・Hyytiälä観測所）におけるCarbonyl Sulfide (COS) フラックスをLong Short-Term Memory (LSTM) ネットワークを用いて予測する最新論文のデータ分析プロセスを、PythonとTensorFlow/Kerasを用いて追試・再現したものです。
本リポジトリでは特に**日次（Daily）スケール**でのFCOS予測に焦点を当て、論文に記載されたハイパーパラメータに基づくモデル構築と、手元のデータセットを用いた実証検証を行っています。

## 使用データと前処理
* **データソース:** Hyytiälä観測所の気象・フラックス観測データ（2013年〜2017年、日次データ）。※論文の記述（4.4節）に従い、2014年のデータは学習・検証から除外しています。
* **入力変数:** 気温 (`Ta`), 地温 (`SoilTA`), 土壌水分 (`SoilWA`), 飽差 (`VPD`), 光合成有効放射 (`PAR`), 葉面積指数 (`LAI`)
* **目的変数:** ギャップフィル済みCOSフラックス (`FCOS_gapfilled`)
* **時系列処理:** MinMaxScalerによる正規化後、Memory Length（Look-back）を20日に設定し、時系列順に70%を学習データ、30%をテストデータに分割。



## モデルの構造とハイパーパラメータ
論文の「Table 2」に記載された設定を忠実に再現しています。
* **モデル:** 単層LSTM (Units: 50, Activation: ReLU) + Dropout (0.2) + Dense (1)
* **最適化手法:** Adam (Learning Rate: 0.01)
* **正則化:** L2正則化 (Weight Decay: 0.0006)
* **バッチサイズ:** 64
* **コールバック:** EarlyStopping (monitor='val_loss', patience=5)

## 分析の目的と結果（考察）
* **目的:** 元論文で示されたモデル構造を用い、手元の限定的な特徴量セットでどの程度の予測精度が再現できるかを検証する。
* **結果:** 構築したモデルを用いたテストデータの評価結果は以下の通りです。
  * **RMSE:** [実際の出力値を入力]
  * **R² (決定係数):** 約0.59 （※論文上のR²は0.86）
* **考察:**
  論文の精度（R²=0.86）に届かなかった最大の要因は、**入力変数の不足**にあると分析しています。論文では上記の観測データに加え、`LST`, `FAPAR`, `NDVI`, `EVI` といった衛星観測データが予測に寄与していますが、本検証で用いたCSVデータにはこれらが含まれていません。このことから、日次スケールのCOSフラックス予測においては、局所的な気象データだけでなく、広域の植生動態を捉える衛星データが精度向上のボトルネック（重要変数）になっていることが実証されました。
